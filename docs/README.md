# Gitup documentation

- **[building.md](building.md)** — toolchains, system libraries per
  distribution, packaging for each platform, and troubleshooting a build that
  will not start.
- **[identity.md](identity.md)** — setting the name and email commits are
  authored under, globally or per repository.
- **[commit-messages.md](commit-messages.md)** — what the Draft button writes,
  how it matches your repository's style, and where it is guessing.
- **[shortcuts.md](shortcuts.md)** — every key binding in both spellings, where
  the settings file lives, and how modifier matching works.
- **[platform-notes.md](platform-notes.md)** — where behaviour differs between
  Windows, macOS, and Linux, and the known limits.
- **[architecture.md](architecture.md)** — how the pieces fit: the job system,
  why network operations shell out to `git`, how partial staging works, and what
  makes the graph and diff views fast.
- **[testing.md](testing.md)** — what the suite covers, why snapshot tests only
  run on macOS, and how to write a test for a bug.
